# Facebook Downloader

Aplicativo desktop em Python para baixar vídeos do Facebook com `yt-dlp`.

## Requisitos

- Python 3.10 ou superior
- Acesso à internet

## Instalação

```powershell
python -m pip install -r requirements.txt
```

## Como executar

```powershell
python main.py
```

Informe o link do vídeo e escolha a pasta de destino. O aplicativo mostra o progresso do download e informa quando ele termina ou apresenta uma falha.

Use somente para baixar vídeos que você tem autorização para salvar e respeite os termos de uso e os direitos dos respectivos titulares.
